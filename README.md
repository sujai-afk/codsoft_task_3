# CodSoft Web Development Internship - Task 3

## Calculator Application

This project is a functional and responsive calculator developed as Task 3 of the CodSoft Web Development Internship.

The calculator is designed to perform basic arithmetic operations through an interactive and user-friendly interface while demonstrating JavaScript event handling and DOM manipulation concepts.

## Features

- Addition, subtraction, multiplication, and division operations
- Clear and delete functionality
- Responsive and modern user interface
- Real-time calculation display
- User-friendly button layout

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Learning Outcomes

Through this project, I improved my understanding of:

- JavaScript fundamentals
- DOM manipulation
- Event handling
- User interface design
- Responsive web development
